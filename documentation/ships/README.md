# Ship hulls

The hull art of the shaped ship types, drawn by `tools/art/generate_svgs.py` from their layouts in
`assets/data/chassis.toml` (the collision layer left out), with the engines the game draws outside the hull. Bow to the right; one tile is 1 m. The size is the layout's grid, engines included; the tiles are the hull's.

| Hull | Owner | Size | In the game |
|---|---|---|---|
| Interceptor | Patrol | 16 x 7, 91 tiles | sold to an Ensign |
| Courier | Selene | 18 x 9, 99 tiles | sold |
| Surveyor | Selene | 25 x 9, 170 tiles | sold |
| Ore Barge | Selene | 20 x 13, 213 tiles | sold |
| Marauder | Void Raiders | 28 x 12, 215 tiles | spawned by name |
| Hospital Ship | Selene | 28 x 19, 310 tiles | spawned by name |
| Propellant Tanker | traders | 40 x 11, 362 tiles | spawned by name |
| Destroyer | Patrol | 35 x 19, 453 tiles | spawned by name |
| Reaver | Void Raiders | 47 x 17, 550 tiles | spawned by name |
| Heavy Cruiser | Patrol | 44 x 23, 592 tiles | spawned by name |
| Bulk Carrier | traders | 48 x 15, 612 tiles | spawned by name |
| Passenger Liner | traders | 44 x 19, 674 tiles | spawned by name |
| Carrier | Patrol | 56 x 33, 1122 tiles | spawned by name |
